# SafetyGuard AI — Practical Project & Viva Guide

An original, responsive learning website inspired by the chapter-based structure, spacing and editorial feel of the reference Cloudlaunch Guide example supplied by the user. No source code or branding from that website is required to run this project.

## Open it locally

Double-click **index.html** in a modern web browser. The site is self-contained: CSS, JavaScript, curriculum content, search, diagrams and the interactive sensor demonstration are embedded in that single HTML file.

## Publish it

Upload the contents of this folder to a static hosting provider such as GitHub Pages, Vercel, Netlify or a standard web server. The guide uses `#/` hash-based routes, so no special server-side routing rules or Node build step are needed.

## Contents

- `index.html` — complete working single-file website (self-contained).
- `data.json` — editable structured curriculum containing **8 modules and 80 lessons**.
- `AI-Test-Lab-full-source-notes.txt` — complete original uploaded AI Test Lab explanation for reference.
- `assets/*.svg` — original editable vector illustrations (monitoring, incident pipeline, synthetic sensors).
- `assets/*-preview.png` — desktop/mobile design previews.

## Interactive capabilities

- 8 module pages, 80 lesson pages, cross-module search.
- Completion tracking stored locally in the viewer's browser.
- Next/previous lesson navigation, mobile curriculum menu and print-friendly lesson view.
- An interactive smoke / temperature **illustration** using the prototype thresholds (300 ppm smoke, 70°C temperature).
- 12-step viva demonstration checklist; local-only completion tracking.
- The original uploaded AI Test Lab notes accessible from the guide.

## Important boundaries

**This is an educational website and demo companion; it is not the SafetyGuard AI backend.** The visuals are original conceptual illustrations, not screenshots of live cameras or actual YOLO predictions. The sensor slider does not create database incidents or make API requests. The guide accurately separates model analysis on uploaded media from TEST incidents generated by the project's simulation endpoint. Prototype rules and settings must not be used as approved industrial safety limits.

The user's full uploaded AI Test Lab write-up is preserved verbatim in the attached text file and reference page. The other module lessons were reconstructed from prior discussion of the prototype and should be checked against the actual current application before publication as authoritative implementation documentation.

No image/video files containing real workers were supplied for this build; no real factory footage is included.
